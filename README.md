# Проектная работа 9 спринта

Задания текущего спринта:

1. Вам нужно провести исследование по выбору хранилища для работы с лайками, закладками и рецензиями пользователей. Предлагаем идти по этому чек-листу:
     * Выбрать хранилище для задачи. Обратите внимание, что в необходимо выбрать хранилище пригодное для множественной записи/чтения одиночных данных. Отличными кандидатами для сравнения будут mongoDB и postgres.
     * Написать скрипт, который генерирует в хранилище данные.
     * Измерить скорость добавления и чтения данных.
     * Отразить результаты тестирования скорости работы с хранилищем в формате .md файла (README.md).

2. Подготовить конфигурационный файл для реализации пайплайна CI с использованием Github Actions. Должны решаться следующие задачи:

      * Настроена проверка линтерами:
          * flake8 желательно заменить на wemake-python-styleguide
          * Сделать вывод в красивый html-файл. В настройках линтеров есть такая опция.
      * Добавить проверку типов с помощью mypy.
      * Сделать проверку работоспособности кода на нескольких версиях python 3.7, 3.8 и 3.9 или 3.10 и 3.11. В этом поможет использование strategy.
      * Добавить отправку сообщения об успешности прохождения CI в телеграм.
      * Сделать срабатывание CI-процесса на новые pull request в master(main)-ветку.
      * Исправить все недочёты, найденные линтерами и статическими анализаторами.

3. Интегрировать [Sentry](https://sentry.io/welcome/) в ваше приложение.
4. Настроить ELK для сбора и хранения логов приложения.
5. Реализовать API для работы с лайками, рецензиями и закладками пользователей, используя выбранное в результате исследования хранилище.
